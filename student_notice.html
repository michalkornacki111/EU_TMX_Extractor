🇪🇺 EU Translation Memory Extractor (DGT-TM)

Official utility for extracting professional bilingual translation memories from European Union legislation

💡 What is this tool and what is it used for?

EU TMX Extractor is a specialized software tool designed for translators, linguists, and translation studies students. It allows you to easily and automatically extract ready-to-use Translation Memories (.tmx files) and bilingual sentence databases (.tsv sheets for Excel) from the official European Union legislative corpus (DGT-TM / Euramis).

In just seconds, the program generates a clean, deduplicated translation memory in your chosen language pair (e.g. English ➔ Polish, German ➔ English, French ➔ Polish, or any combination of the 24 official EU languages). Output files are 100% compliant with the international TMX 1.4 standard and ready for instant import into industry-standard CAT tools (SDL Trados Studio, memoQ, OmegaT) or spreadsheet analysis.
