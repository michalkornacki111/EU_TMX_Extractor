⚡ Quick Start: 1-Click Launchers (No Terminal Needed)

The software includes ready-to-run launchers for each operating system. You do not need to open a terminal or type any commands:

🪟 Windows (10 / 11)

Double-click the batch file in the program folder:

run_windows.bat

Also compatible with uruchom_windows.bat. Automatically enables UTF-8 and ANSI colors in Command Prompt.

🍎 macOS (Apple Silicon / Intel)

Double-click the command file in the program folder:

run_mac.command

If macOS shows an unidentified developer notice: right-click the file and choose Open.

🐧 Linux (Ubuntu, Debian, Fedora)

Double-click or run the shell script:

./run_linux.sh

Alternatively, run python3 tmx_extractor.py from the terminal.

⚠️ Compulsory First Step:
Always extract (unzip) the entire EU_TMX_Extractor.zip archive to a real folder on your drive (e.g., Desktop or Documents) before double-clicking the launcher. Do not run directly from inside the compressed ZIP window!

📥 1. One-Time Python Installation (Done Once)

EU TMX Extractor runs on the free, official Python runtime. If Python is not already installed on your computer, follow the instructions below:

For Windows Users:

  1. Go to the official website: https://www.python.org/downloads/
  2. Click the large yellow button: Download Python 3.12 (or newer).
  3. Launch the downloaded installer file (python-3.12.x-amd64.exe).
  4. 🚨 THE MOST CRITICAL STEP ON WINDOWS:
    On the very first screen of the installer, look at the bottom and check the checkbox:
    ☑ Add python.exe to PATH
    (If this checkbox is omitted, Windows will not recognize the python command!)
  5. Click Install Now and wait for completion. You are done!

For Mac (macOS) Users:

  1. Go to: https://www.python.org/downloads/macos/
  2. Download the macOS 64-bit universal2 installer (.pkg).
  3. Open the installer package and follow the standard on-screen wizard.

🧙 2. The 5-Step Interactive Wizard

When you double-click the launcher, the program opens an interactive step-by-step assistant. Each step clears the console window and displays a top breadcrumb banner, ensuring that the active prompt is always clearly visible at line 0 without requiring manual scrolling.

Step 1 of 5: Source Data Location

The program automatically scans your folder and downloads directory for ZIP archives and TMX files.

  • Option [W]: Process ALL detected ZIP archives one by one (Batch mode).
  • Option [1..N]: Select a specific local ZIP archive found in the folder.
  • Custom path: Enter a custom file or folder path.
  • Download: Connect to official data.europa.eu repositories.

Step 2 of 5: Target Language Pair

Select from the most popular EU language combinations (e.g., [1] English -> Polish (EN -> PL), German -> Polish, French -> English) or type any custom language pair. The engine accepts both 2-letter ISO codes (EN, PL, DE) and full English/Polish language names (polish, polski, french).

Step 3 of 5: CAT RAM Protection & Segment Splitting

Very large TMX files (>100,000 translation units) can overwhelm RAM and freeze SDL Trados Studio or memoQ. The extractor provides built-in chunking:

  • [1] Split every 50,000 segments: Recommended for optimal CAT stability. Output is sequenced into _part01.tmx, _part02.tmx, etc.
  • [2] Split every 100,000 segments: For high-end computers.
  • [3] Custom segment limit: Enter any custom segment threshold.
  • [4] No splitting: Generate a single large output file.

Step 4 of 5: Output Format and File Naming

  • TMX (.tmx): Industry-standard Translation Memory exchange format (100% compliant with TMX 1.4).
  • Excel / TSV (.tsv): Tab-separated bilingual spreadsheet ready to open in Microsoft Excel.
  • TMX + Excel/TSV: Both formats generated simultaneously in a single pass.
  • JSONL (.jsonl): Clean structured format for AI model fine-tuning.

Step 5 of 5: Quality & Deduplication Options

  • Deduplication [Y/n]: Removes redundant repetitions, keeping only unique sentence pairs.
  • Identical Segment Filter [Y/n]: Filters out non-translatable units where source and target are identical (e.g. pure digits, article numbering).
  • Max pairs limit: Leave blank for no limit, or specify a test limit (e.g. 1000).

🗂️ 3. Batch Extraction: Process All ZIPs One by One

If your project requires processing multiple volumes (for instance, all 5 volumes of year 2025 or multiple historical years), the batch processing engine handles the entire list automatically in sequence:

How Batch Mode Operates:

  1. Detects all ZIP archives in the directory (e.g., Vol_2024_1.zip, Vol_2024_2.zip, Vol_2025_1.zip).
  2. Processes each archive independently, creating dedicated output files (e.g., Vol_2024_1_en_pl.tmx) and individual reports.
  3. Fault-tolerant: If one archive is corrupted or incomplete, the program reports a warning and continues processing the remaining archives without crashing.
  4. Generates a comprehensive Master Batch Report (batch_summary_report_en_pl.txt) summarizing total sentence pairs, elapsed time, and per-archive statistics.

🌐 4. Official EU Datasets & Repository Download

The European Commission publishes bilingual legal translations under the DGT-TM open dataset at data.europa.eu.

📂 WHERE SHOULD YOU SAVE DOWNLOADED ZIP FILES?
Save downloaded .zip files directly inside the folder of this program (the folder containing run_windows.bat and tmx_extractor.py).
The program automatically scans its own folder at startup and displays all detected archives in the Step 1 menu!

Downloading the ENTIRE Official Repository (2004–2025)

Version 2.4 allows you to download all 87 official volumes directly from within the program:

  • Select option [W] DOWNLOAD ENTIRE REPOSITORY AT ONCE in the download menu.
  • Pre-flight Storage Summary: The program calculates local disk usage, estimates total transfer size (~7.6 GB), and verifies that you have sufficient free space before downloading.
  • Resume & Skip: Any files already downloaded locally are verified for ZIP integrity and skipped.
  • Post-Download Prompt: When the transfer finishes, the program asks whether you wish to proceed immediately to batch TMX extraction or exit.

💼 5. Importing Generated Memories into CAT Tools

1. SDL Trados Studio

  1. Open SDL Trados Studio and go to the Translation Memories view.
  2. Click New ➔ New Translation Memory (select your source and target language).
  3. Right-click your newly created translation memory and choose Import.
  4. Click Add Files... and select your generated .tmx file (or all chunk files _part01.tmx, _part02.tmx).
  5. Click Finish. Your official EU translation memory is ready for active translation!

2. memoQ

  1. Open memoQ and navigate to Resource Console (the book icon in the top left).
  2. Click Translation Memories in the left sidebar.
  3. Click Create new or select an existing memory with matching language pair.
  4. Click Import from TMX/CSV in the operations bar.
  5. Select the .tmx file and click Open ➔ OK.

3. OmegaT

  1. Open your OmegaT project folder.
  2. Locate the subfolder named /tm.
  3. Copy your generated .tmx file directly into the /tm folder.
  4. In OmegaT, press Ctrl+R (or Cmd+R on Mac) to reload project memories.

4. Microsoft Excel / Spreadsheets

If you chose format [2] TSV in Step 4: Open Microsoft Excel ➔ File ➔ Open ➔ Choose All Files (*.*) ➔ Select your .tsv file. Excel will open it cleanly formatted into 3 columns: Source, Target, and Document_ID (CELEX).

❓ 6. Frequently Asked Questions (FAQ) & Troubleshooting

Q: Windows says "Python was not found" or closes immediately when launching.

Fix: Python was installed without the PATH environment variable. Relaunch the Python installer, choose Modify, and ensure the checkbox [X] Add python.exe to PATH is checked.

Q: Why does the program split output into _part01.tmx, _part02.tmx?

Reason: Very large TMX files (>100,000 translation units) can cause out-of-memory errors in CAT tools during indexing. Chunking into 50,000 segments ensures 100% reliable import. If you want a single file, select option [4] No splitting in Step 3.

Q: Are special characters (diacritics, quotes, XML tags) safely preserved?

Yes: The extractor enforces UTF-8 across all streams and standard XML escaping (&amp;, &lt;, &gt;, &quot;). Accented characters in all 24 EU languages are fully preserved.
